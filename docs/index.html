flowChart

Type what you mean. Get an editable mind map or flowchart. No internet, no account, no data leaves your machine.

Download for Windows, macOS or Linux Source on GitHub

Free and open source (MIT). First launch downloads the 1.1 GB model once, then it works offline forever.

> how a support ticket gets resolved
Start→Receive ticket→Assign agent→Resolved?yes →Close ticket→End

Runs on your laptop

A 1.7B-parameter open model (Qwen3, Apache-2.0) through llama.cpp. Uses your GPU when there is one, CPU otherwise.

Streams onto the canvas

Nodes appear and lay themselves out while the model is still writing.

Actually editable

Rename, change shapes (start, step, decision, end), connect, delete, add. It is a real diagram, not a picture.

Export anywhere

PNG, PDF, PowerPoint, Word.

Bring your own model

Optional: paste an Anthropic, OpenAI, Gemini or OpenRouter key for richer diagrams. Stored encrypted, sent only to that provider.

Private by design

No telemetry, no account, no server. Read the code.
